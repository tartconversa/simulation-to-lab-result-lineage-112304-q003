# 资料契约

所有记录均为本地合成数据，使用 UTC 时间或 ISO 日期。标识字段用于关联文件，版次、状态、缺失、撤回和待审核值保留各自原始含义。

| 文件 | 字段 | 记录数 |
| --- | --- | ---: |
| `simulation_runs.csv` | `simulation_id`, `model_id`, `model_version`, `input_hash`, `seed`, `environment`, `started_at`, `result_ref` | 90 |
| `lab_runs.csv` | `experiment_id`, `sample_id`, `protocol_version`, `instrument_id`, `started_at`, `run_state`, `result_ref` | 75 |
| `measurements.csv` | `result_ref`, `metric`, `value`, `unit`, `uncertainty`, `replicate_no` | 120 |
| `validation_links.csv` | `link_id`, `simulation_id`, `experiment_id`, `condition_map_version`, `review_state`, `reviewer`, `decision_at` | 60 |

缺失值、争议状态、部分成功和待复核均不表示零值或已完成。原始值不预置分析结论，转换依据及研究解释须由应用能力提供。

## 应用层补充约定

- 应用数据库（SQLite）在内部 `measurements` 表增加 `batch_id` 列记录测量行的接入批次；
  上游 CSV 契约保持不变，该列由接入过程自动写入。
- 悬空测量引用（不属于任何仿真/实验结果）的原始行保留，但登记
  `orphan_result_ref` 问题且不参与任何比较事实。
- 基线数据中仿真侧指标（binding/energy）与实验侧指标（stability/yield）不重合，
  所有验证链接在应用中判为 `not_comparable`；这是数据现状的真实表达，不应通过
  隐式单位换算或指标映射强行得到验证/否定结论。
- 应用能力、判定规则与操作手册见 `docs/应用说明.md`。
